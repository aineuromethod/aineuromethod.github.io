1. Интеграция реального AI-движка
Подключён OpenAI API (модель gpt-4o) с использованием ключа.

Демо-заглушки заменены на «живые» запросы: при отправке формы вызывается функция callOpenAI, которая передаёт системный промпт и пользовательский ввод.

Ответ принудительно структурирован: API возвращает строгий JSON (response_format: { type: "json_object" }), что обеспечивает корректное отображение в карточках интерфейса.

2. Уникальные системные инструкции для каждого инструмента
Для каждого из шести инструментов подготовлен отдельный системный промпт (systemPrompt), который определяет роль AI, требуемые поля и формат ответа.

Инструменты получили готовые сценарии для демонстрации (пример задачи от заказчика «производственная обувная компания, продавцы B2B и юридическая грамотность»), что гарантирует предсказуемый и качественный результат на презентациях.

3. Расширение ввода: голос, текст, файл
Во все инструменты добавлена возможность загрузки файла (TXT, PDF, DOC/DOCX).

Реализована обработка PDF через библиотеку pdf.js: текст извлекается из документа и добавляется в запрос к AI.

Голосовой ввод (Web Speech API) сохранён и продолжает работать параллельно.

4. Интерфейс и визуальные доработки
Усилены заголовки «Что на входе» / «Что на выходе»: в карточках инструментов добавлен более жирный шрифт (font-weight: 600) и увеличен отступ между блоками, чтобы улучшить читаемость.

Формы инструментов теперь динамически показывают поле загрузки файла только там, где это необходимо (например, в «Смысловике»).

Виджет заявки перенесён в правую часть блока и инициализируется через безопасный скрипт, не затрагивая остальную функциональность.

5. Архитектура и безопасность
Сохранена парольная защита (admintest) – запрос к API выполняется только после успешного ввода пароля в модальном окне.

Ключ API временно размещён в коде как решение для MVP. В продакшене потребуется вынос на серверный прокси.

Код полностью переписан с учётом новой логики, но сохранена полная обратная совместимость с существующим дизайном и адаптивной вёрсткой.

Эти изменения превращают сайт из демонстрационного макета в полностью функциональный AI-инструмент для проектирования обучения, готовый к тестированию и демонстрации.
