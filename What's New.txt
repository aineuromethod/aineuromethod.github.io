AI-ДВИЖОК И ИНСТРУКЦИИ

• Интегрирована система загрузки внешних инструкций для каждого инструмента.
При запуске любого из шести инструментов автоматически загружаются
соответствующие MD-файлы из папки «Instructions», которые дополняют
системный промпт и обеспечивают строгое соответствие методике.
• Инструкции внедрены для всех инструментов:

Бриф AI: 6 файлов (kb_01–05 + Главная бриф.md)

Профиль AI: 5 файлов (system_instruction, methodology, rules, templates + Главная Профиль.md)

Диагност AI: 3 файла (expert_pack, templates + Главная диагност.md)

Смысловик AI: 7 файлов (KB_00–05 + Главная Смысловик.md)

Логик AI: 1 файл (Главная Логик.md)

Практик AI: 6 файлов (KB_00–04 + Главная Практик.md)
Загрузка происходит асинхронно и не блокирует интерфейс.
• Сохранена парольная защита: запрос выполняется только после успешного
ввода пароля.
• Подключён реальный AI через OpenAI API (модель gpt-4o-mini) с
использованием нового рабочего Secret Key.
• Ответ AI принудительно форматируется в JSON для корректного отображения
в карточках интерфейса.
• Увеличена допустимая длина ответа (снято ограничение), чтобы получать
развёрнутые результаты.
• Для стабильной работы на GitHub Pages реализован механизм перебора
нескольких публичных CORS-прокси:

corsproxy.io

api.codetabs.com

cors-anywhere.herokuapp.com
При недоступности всех прокси выводится понятное сообщение.
